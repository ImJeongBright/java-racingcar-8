# 기능 요구사항

- [x] 자동차 이름 입력
  - [x] 이름은 쉼표를 기준으로 구분한다.
  - [x] 이름은 5자 이하여야 한다.
  - [x] 해당 조건들이 지켜지지 않을 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료되어야 한다.


- [x] 시도 횟수 입력
  - [x] 사용자로부터 시도할 횟수를 입력받는다.
  - [x] 횟수는 자연수만 입력 가능하다.
  - [x] 해당 조건들이 지켜지지 않을 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료되어야 한다.


- [x] 게임 차수별 실행 결과 출력
  - [x] 각각의 게임이 실행될 때마다 자동차의 이름과 함께 현재 위치를 출력한다. ex)
    ```
        실행 결과
        pobi : -
        woni :
        jun : -
    ``` 
    - [x] 모든 횟수를 진행하면 최종 우승자를 출력한다.
    

- [x] 우승자 안내 문구 출력
    - [x] 완료된 게임에 대한 우승자를 출력한다.
    - [x] 우승자가 여러명일 경우 쉼표를 이용하여 구분한다.


- [x] 게임 기능
  - [x] 각 자동차는 매 게임마다 무작위 값을 받는다.
  - [x] 무작위 값이 4이상일 경우 전진한다.
  - [x] 무작위 값이 3이하일 경우 이동하지 않는다.
